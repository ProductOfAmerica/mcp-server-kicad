# Getting help

- **A question about using the server** (setup, configuration, which tool does what): ask in [Discussions Q&A](https://github.com/ProductOfAmerica/mcp-server-kicad/discussions/categories/q-a). Most setup problems are covered in the README's [Requirements](README.md#requirements) and [Debugging](README.md#debugging) sections, so check those first.
- **Something is broken**: open a [bug report](https://github.com/ProductOfAmerica/mcp-server-kicad/issues/new?template=bug_report.yml).
- **An idea for a new feature**: open a [feature request](https://github.com/ProductOfAmerica/mcp-server-kicad/issues/new?template=feature_request.yml).
- **A security vulnerability**: follow [SECURITY.md](SECURITY.md). Never open a public issue for one.
